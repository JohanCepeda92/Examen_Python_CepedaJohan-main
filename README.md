# 📚 Generador de Horarios para Estudiantes

Proyecto desarrollado en Python para gestionar y organizar el horario semanal de un estudiante.

## 🎯 Descripción

El programa permite registrar materias o actividades, consultar el horario semanal, modificar o eliminar actividades y generar un reporte del horario.

La información del horario se almacena en archivos JSON.

## ⚙️ Funcionalidades

El programa cuenta con las siguientes opciones:

1. Registrar una materia o actividad.
2. Ver el horario semanal.
3. Modificar una materia o actividad.
4. Eliminar una materia o actividad.
5. Generar un reporte del horario.
6. Salir del programa.

## 🛠️ Tecnologías utilizadas

- Python
- JSON
- Visual Studio Code
- Git y GitHub

## 📁 Estructura del proyecto

- `main.py` → Ejecuta el programa y muestra el menú principal.
- `funciones.py` → Contiene las funciones principales del programa.
- `datos.py` → Maneja los datos del horario.
- `horario.json` → Guarda la información del horario.
- `reporte_horario.json` → Guarda el reporte generado.
- `.gitignore` → Evita subir archivos innecesarios como `__pycache__` y archivos `.pyc`.

## ▶️ Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar el archivo `main.py`.
4. Seleccionar una opción del menú.
